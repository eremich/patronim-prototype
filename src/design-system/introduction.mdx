| Components, one per file, props only | `src/components/*.tsx` |
| Stories and docs next to each component | `src/components/*.stories.tsx`, `*.mdx` |

## Principles

- **One bold element, everything else calm.** The turnover window bar is the only loud thing on a screen.
- **Tokens only.** No raw hex, radius or font size in components. Missing a value? Add a token.
- **Two themes, one set of names.** Light and dark are data in `tokens.js`; switch with the theme toolbar.
- **Status is never color alone.** Every status has an icon and a text label.
- **Props in, events out.** Components never read the app store, so they render here exactly as in the app.
