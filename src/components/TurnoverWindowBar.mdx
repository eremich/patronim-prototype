# Turnover window bar

<Lead>
  The one bold element of Patronim. Checkout on the left, the next guest's check-in on the right, the cleaning block
  inside and a "now" marker. It answers one question for every role: will the apartment be ready before the guest arrives?
</Lead>

<Canvas of={Stories.Cleaning} />
<Controls of={Stories.Cleaning} />

## Anatomy

| Part | Meaning |
| --- | --- |
| Left time | Guest checkout. Work can start from here |
| Right time (bold) | Guest check-in. The deadline |
| Solid block | Cleaning already done |
| Hatched block | Cleaning still to do (planned or projected) |
| Navy tail | Inspection, 30 min after the clean |
| Black line and "Now" pill | Current time. Hidden when outside the window or once ready |
| Hatched red area past a black line | Time the cleaning runs past check-in |
| Caption | The verdict in words: "30 min to spare", "Finishes 40 min after check-in" |

## Health

<Canvas of={Stories.CompactStates} />

| Health | When | Color |
| --- | --- | --- |
| On track | Cleaning and inspection end before check-in | `ok` |
| At risk | Cleaning ends in time, inspection does not | `risk` |
| Late | Cleaning itself ends after check-in | `late` |

## Where it appears

- **Manager:** Today list (compact), Book a cleaning (full, live preview), Job tracking (full).
- **Cleaner:** Jobs list (compact), Job detail (full).
- **Inspector:** Queue (compact).

## Accessibility

- Rendered as `role="img"` with a full sentence label: window, cleaning times and verdict.
- The verdict caption uses the `-ink` text shades (AA). Fills use the brief colors.
- Times use tabular numerals so they don't shift while updating.
